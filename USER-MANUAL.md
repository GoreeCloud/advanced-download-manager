# GoreeCloud Advanced Download Manager — User Manual

## Current availability

GoreeCloud Advanced Download Manager is currently in **Concept** lifecycle. This repository does not yet contain a supported download engine, desktop application, Android application, installer, package, daemon, or CLI that users can operate.

There are therefore no supported installation, setup, download, queue, scheduling, browser-integration, remote-control, or recovery procedures to follow yet.

## What is being developed

The planned product is a local-first download manager for Linux, Windows, and Android with a shared download engine. Planned capabilities include durable resume, intelligent acceleration, queues, bandwidth and scheduling controls, rules, verification, browser handoff, automation, and optional authorized GoreeCloud integrations. Planned capabilities are not current user instructions.

## Accounts and connectivity

Core downloading is intended to remain usable without a GoreeCloud account. GoreeCloud Identity, Mesh, Manager, remote control, and synchronization are planned optional layers, but no application-specific runtime integration is currently accepted.

## Privacy and security

Because no runtime download implementation exists yet, this repository is not currently processing a user's download URLs, credentials, history, files, or transfer metadata as an application. The planned runtime privacy/security model is described in `PRIVACY POLICY.md`, `SECURITY.md`, and `SPECIFICATIONS.md`; those plans do not establish current runtime protection.

## Getting help during Concept development

Use the repository documentation to understand planned scope and current status. Do not rely on commands, package names, screenshots, or third-party builds that are not documented as supported by an authoritative GoreeCloud release.

This manual will be expanded when verified user-operable behavior exists. At that point it must describe only supported installation, configuration, workflows, limitations, recovery, and troubleshooting.
