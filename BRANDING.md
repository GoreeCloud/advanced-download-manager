# GoreeCloud Advanced Download Manager — Branding

## Canonical identity

- **Product name:** GoreeCloud Advanced Download Manager
- **Repository:** `GoreeCloud/advanced-download-manager`
- **CLI working command name:** `gcdm` is planned in the specification but is not implemented.
- **Design system:** Glaze UI, using the current approved Stable consumer contract at implementation and acceptance time.

The product should be recognizably GoreeCloud while preserving a functional, transfer-focused identity. User-facing state must rely on text and symbols as well as color. Downloading, completed, waiting, failed, verifying, and processing states should remain distinguishable under high-contrast and reduced-transparency settings.

Do not claim Glaze UI conformance until application-specific implementation and acceptance evidence exists. Current Concept-stage repository documentation does not establish a visual implementation, icon, shipped theme, or approved runtime interface.

Product artwork and icons must come from approved GoreeCloud branding assets or a later authorized product-specific asset source; temporary repository imagery must not silently become canonical branding.
