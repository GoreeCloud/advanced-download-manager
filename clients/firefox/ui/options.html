Download Manager settings

GoreeCloud Download Manager Extension 0.2.18

Downloads

Choose the transfer engine and behavior shared across managed downloads.
Per-download destination
GoreeCloud-started Firefox downloads always open Save As. Downloads Firefox starts itself use Firefox Settings → General → Downloads → Always ask you where to save files.
Automatically manage Firefox downloads
Adds ordinary HTTP/HTTPS downloads that Firefox starts to GoreeCloud Download Manager without cancelling or replaying the request. Automatically captured downloads stay on Firefox's engine; native segmented mode applies only to downloads started through GoreeCloud controls.
Completion and failure notifications
Show a Firefox notification when a managed download completes, fails, or is interrupted.

Native acceleration

Segmented downloads, durable resume, and optional authenticated transfers.
Off
Switch the Download engine to Native segmented helper to configure acceleration.
Forward target-site cookies
Off by default. When enabled, GoreeCloud can pass cookies for the target download URL to the local native helper in memory.
Firefox may call this optional grant “Access your data for all websites.” GoreeCloud requests it only after native mode and cookie forwarding are both selected.
