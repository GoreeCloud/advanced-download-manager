Download Manager settings

GoreeCloud Download Manager Extension 0.2.16

Downloads

Choose the transfer engine and behavior shared across managed downloads.
Per-download destination
Firefox-engine downloads started from GoreeCloud controls always open Firefox's Save As dialog so you choose the destination and filename for each transfer. For automatically captured downloads that Firefox has already started, enable Firefox Settings → General → Files and Applications → Downloads → Always ask you where to save files; GoreeCloud deliberately does not cancel and replay those requests.
Automatically manage Firefox downloads
Adds ordinary HTTP/HTTPS downloads that Firefox starts to GoreeCloud Download Manager without cancelling or replaying the request. Automatically captured downloads stay on Firefox's engine; native segmented mode applies only to downloads started through GoreeCloud controls.
Completion and failure notifications
Show a Firefox notification when a managed download completes, fails, or is interrupted.

Native acceleration

These controls apply only when the native segmented helper is the selected download engine.
Inactive
Forward target-site cookies to the native helper
Off by default. When deliberately enabled in native mode, Firefox can grant optional Cookies + All Sites access. GoreeCloud forwards only cookies for the target download URL to the local native process in memory and does not intentionally store them in download history.
Firefox may describe this optional permission as “Access your data for all websites.” GoreeCloud will not request it unless native mode and cookie forwarding are both selected.
